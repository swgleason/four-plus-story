# Four Plus Story Library - Mobile Application

Cross-platform mobile client (iOS & Android) for church members and the public to:
- Discover and read approved 4+ stories.
- Search stories semantically (by emotion, theme, struggle, or scripture) and by keywords.
- Filter by story variant (Distress to Peace, Appreciation / Joy-Spreading, Rupture and Repair, Endurance & Hope).
- View STEP breakdowns (Situation, Thought, Emotion & Sensation, Presence & Peace).
- Save favorites, track reading history, and share stories with relational communities.

## Key Stack
- React Native + Expo SDK 52+
- TypeScript
- Supabase Mobile Client
- `@four-plus/shared-types`
